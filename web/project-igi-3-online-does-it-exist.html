Project I.G.I. 3 Online: Does the Game Exist?

A clear distinction between the original Project I.G.I., I.G.I.-2: Covert Strike and the announced I.G.I. Origins project.

Quick answer

There is no officially released game titled Project I.G.I. 3 available to play here. A third series entry was announced under the name I.G.I. Origins, previously referred to as Project I.G.I. 3, but the official Steam listing currently shows its release date as “To be announced.” This website does not run I.G.I. Origins.

Project I.G.I. 3 Online: What Does This Site Run?

The browser player on this site is for Project I.G.I.: I'm Going In, the original 2000 game developed by Innerloop Studios and published by Eidos Interactive. It is not a new sequel, remake or Origins build. You must supply your own legally obtained copy of the original game files.

What about I.G.I.-2: Covert Strike?

I.G.I.-2: Covert Strike is a separate sequel released in 2003. It should not be confused with the original Project I.G.I. from 2000 or with I.G.I. Origins. The PCGamingWiki series listing distinguishes the original game, I.G.I.-2 and I.G.I. Origins as separate entries.

What was I.G.I. Origins?

I.G.I. Origins was announced as a prequel set in the Cold War era. The official Steam product page lists Antimatter Games as developer and publisher and currently displays the release date as “To be announced.” The Steam listing is the best place to check its current public status. Do not trust unofficial “Project IGI 3 download” pages that present unrelated files as an official release.

Official listing: I.G.I. Origins on Steam. Historical series context: PCGamingWiki Project I.G.I. series.
