Project I.G.I. Online: Frequently Asked Questions

Straight answers about the browser port, game files, controls, compatibility and troubleshooting.

Can I play Project I.G.I. online in a browser?

Yes. This browser port can run the original 2000 Project I.G.I. game when you import your own legally obtained game files. The website does not host the original game data.

Is Project I.G.I. free here?

The website is free to access and does not require sign-up or a separate installer. You must provide your own legally obtained game copy; “free” does not mean the original commercial game is included or available for download.

Do I need to download the game from this website?

No. Select your own installed game folder when the launcher asks for it. This site does not distribute the original game files.

Where are my game files stored?

The browser copies the selected files into private browser storage for this website. They are not uploaded to the site's server as part of the import flow. Clearing site data may delete the imported copy.

Can I play on a Chromebook?

Chromebook support depends on the ChromeOS version, browser graphics support, available memory and WebGPU availability. This site does not guarantee compatibility with every Chromebook model. If the game fails to start, check browser updates, graphics support and memory pressure.

Can I play on Android or a tablet?

The project includes a touch interface for supported phones and tablets. Actual performance depends on browser support, memory, graphics hardware and device policies. Motion-sensor access may be restricted by the browser.

Does it support touch controls and gyro aiming?

The current project code documents an on-screen touch layout and gyroscope aiming on compatible devices. Gyro use may require browser permission; touch swipe aiming is an alternative.

Does it support widescreen?

The build includes a widescreen display option for the 3D view. Menus and scoped views may retain 4:3 proportions.

Does the original game have multiplayer?

No. The original Project I.G.I.: I’m Going In campaign is single-player. This browser project adds a separate online 1v1 room feature with host and join controls. That web feature depends on the room service being reachable, so a room may not be available on every visit or network.

Why is the game black or not loading?

Wait for browser checks and runtime preparation. Confirm that you selected the correct game folder, update your browser, check WebGPU support and close memory-heavy tabs. A black screen after a crash can indicate the browser ran out of memory or lost its graphics device.

How do I keep my imported copy?

Do not clear this website's storage, use private browsing, or switch browser profiles if you want the imported copy to remain available. Keep a backup of your original files.

Is this the official Project I.G.I. website?

No. This is an unofficial fan project and is not affiliated with or endorsed by the original developers or publishers.

Can I play Project I.G.I. 3 here?

No. This player runs the original Project I.G.I.: I'm Going In (2000), not I.G.I. Origins. See our IGI 3 explainer.
