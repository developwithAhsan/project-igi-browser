How to Play Project I.G.I. in Your Browser

Project I.G.I. is a classic tactical shooter, and the browser port has a few setup steps worth understanding before the first mission.

Last updated: 30 October 2026 · Beginner guide · 4 min read

Start with a modern desktop browser that supports WebAssembly and the graphics features used by the port. Allow the page to complete its browser checks and runtime setup before selecting Play. Depending on your setup, the loader may ask you to select your own legally obtained Project I.G.I. game folder. The original game data is not distributed by this fan page.

Once the game is ready, use the live Controls & Settings panel to learn the current bindings. Click a rebindable key and press the replacement input. If you are on a phone or tablet, choose the touch layout and rotate to landscape when requested.

For the smoothest start, close other memory-heavy tabs, keep the browser updated and avoid private browsing if you need local browser storage to persist.
