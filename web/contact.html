IGI ONLINE / CONTACT

Contact IGI Online

Contact the IGI Online site team about technical problems, feedback or intellectual-property requests.

Technical issues and feedback

For a technical issue, include your browser name and version, device model, operating system, the step where the issue occurs and the exact error message. Do not attach or share copyrighted game files.

For public technical reports, you can use the project GitHub issue tracker. Do not post personal information or private correspondence in a public issue.

Copyright and takedown requests

Rights holders should use a private, verified contact channel. A public contact email has not yet been supplied by the site owner, so this page does not publish an unverified address. See the DMCA and takedown information.

Response expectations

This is a small independent fan project. A response time is not guaranteed. Please include enough information to reproduce a technical problem without sharing the original game data.
