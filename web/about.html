About IGI Online

Learn about this independent fan-made Project I.G.I. browser port, how local game-file import works and what the site provides.

What this project is

IGI Online is an independent fan-made website for a browser port of the original Project I.G.I.: I'm Going In (2000). It brings the game launcher, controls panel and setup information together in one place.

How the browser port works

The browser runtime uses WebAssembly and WebGPU. Players select their own legally obtained game folder; the browser copies those files into private storage for this site. The website does not host or distribute the original commercial game data.

What is documented in this build

  • Keyboard and mouse controls with configurable bindings.
  • Touch controls for supported phones and tablets.
  • Gyroscope aiming on compatible devices and browsers.
  • A widescreen display option, with some views retaining 4:3 proportions.
  • Browser storage for the imported game files.
