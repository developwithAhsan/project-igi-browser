02 / ABOUT THE GAME

Enter the world of Project I.G.I.

Project I.G.I.: I'm Going In is a first-person tactical stealth shooter originally released in 2000. You play as David Jones, a former SAS soldier working through high-risk missions that reward observation, planning and controlled action.

Use the environment, long-range weapons, equipment and careful movement to infiltrate enemy positions. Its large outdoor areas and mission-based structure helped make it a memorable PC shooter.

This is an unofficial fan page and does not include or distribute the original copyrighted game data.

05 / TIPS & TRICKS

Field notes before deployment

  • Study the area before moving into an exposed position.
  • Use cover and avoid unnecessary noise when possible.
  • Keep an eye on ammunition and reload between encounters.
  • Use long-range optics to assess distant threats.
  • Rebind keys if the default layout does not suit your setup.
  • Close memory-heavy browser tabs if performance becomes unstable.
  • Use landscape mode and a physical keyboard for desktop-style play.
  • Keep browser storage intact if you rely on locally saved data.

06 / FAQ

Frequently asked questions

Is Project I.G.I. free to play here?

This browser page is free to access. Original game data is not distributed here; you may need your own legally obtained copy.

Do I need to download or install anything?

The browser runtime loads on the page. Depending on your setup, you may need to select your own Project I.G.I. game folder when prompted.

Which browsers work best?

Use an up-to-date desktop browser with WebAssembly and WebGPU support where available. Performance and compatibility vary by device.

Why is the game not loading or lagging?

Allow runtime preparation to finish, close memory-heavy tabs, and check that your browser supports the required graphics features.

How do I use fullscreen?

Use the fullscreen control on the game window or press Alt + Enter where supported. Mobile browsers may handle fullscreen differently.

Can I play on mobile?

The project includes a touch interface for supported phones and tablets, but performance depends on device memory, graphics support and browser behavior.

How do I save my progress?

Save behavior depends on the game runtime and browser storage. Avoid clearing site data or using private browsing if you need persistent local data.

What are the controls?

See the live Controls & Settings panel beside the game. You can rebind supported keys and adjust mouse settings there.

Is this the official version of Project I.G.I.?

No. This is an unofficial fan-accessible page and is not affiliated with or endorsed by the original developers or publishers. See the Disclaimer.

How can I report a problem or contact you?

Use the Contact page to report a technical issue or send a message.
