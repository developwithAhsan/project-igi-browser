Project I.G.I. 1 Online: The Original 2000 Game

This page explains the original Project I.G.I. and how to use this browser port with your own game files.

Quick answer

This browser edition runs Project I.G.I.: I'm Going In, the original tactical first-person shooter released in 2000. You must import your own legally obtained game files; this website does not host or distribute the commercial game data.

What is Project I.G.I. 1?

Project I.G.I.: I'm Going In is a single-player tactical first-person shooter developed by Innerloop Studios and published by Eidos Interactive. It was released for Windows in 2000. Its gameplay combines first-person combat with reconnaissance, stealth, equipment use and mission objectives. These historical details are supported by contemporary game databases and preservation references; see the PCGamingWiki game record and the IGDB press kit.

How this browser edition works

The website provides a browser-based port and a launcher interface. It does not supply the original game executable, missions, textures, audio or other copyrighted data. Select the folder from your own lawful copy when the launcher requests it. The browser copies the selected data into its private origin storage so later sessions can reuse it. Your files are not uploaded to this website's server.

What you can configure

The current build documents keyboard and mouse remapping, mouse sensitivity, touch controls for supported phones and tablets, gyro aiming where the browser exposes motion sensors, and a widescreen display option. Availability depends on the browser and device. Use the live controls panel as the authority for the options exposed by the current build.

Start playing

Open the Project I.G.I. browser player, wait for the browser checks, then select your own game folder when prompted. The first import can take time. Keep browser site data intact if you want to avoid importing the same files again.
