Project I.G.I. Controls: Keyboard, Mouse & Touch

Use the live settings panel in the game for the exact bindings and options available in your current session.

Keyboard and mouse

The desktop control panel supports configurable keyboard bindings and mouse settings. The current port allows keys to be rebound from the settings panel and includes a Modern (WASD) layout option. Mouse sensitivity and mouse-button actions can also be configured. The exact active mapping shown in the player is authoritative; check it before assuming a key performs a particular action.

Touch controls

On supported phones and tablets, the project includes an on-screen movement stick and action buttons. The touch interface includes options to adjust the layout, size and opacity of controls. A sprint lock, scope control and touch interactions for the game's menus are also documented in the build. Device performance and browser compatibility vary.

Gyroscope aiming

Gyroscope aiming is available on compatible devices and browsers that expose motion sensors. It can be configured for scoped aiming or other supported modes, and the settings include sensitivity and axis options. Some browsers require a user gesture or explicit permission. If motion input is unavailable, use swipe aiming.

Widescreen display

The build includes a widescreen display option. The game can adjust its 3D viewport and field of view to wider windows, while some menus and scoped views remain proportioned as 4:3. If the display looks wrong, compare the widescreen setting with the default and avoid changing browser zoom while diagnosing it.

Fullscreen and browser input

Use the fullscreen control inside the game window. Browser fullscreen and pointer lock require user interaction and may behave differently on mobile devices. On desktop, the page also documents Alt + Enter where supported. Press Escape according to the in-game prompt; the game menu and browser fullscreen behavior are separate controls.

Open the player

Go to the Project I.G.I. browser player and use the live Controls & Settings panel. For setup problems, see the FAQ or the browser safety guide.
