Project I.G.I. Controls: Keyboard, Mouse & Touch

Use the live settings panel in the game for the exact bindings and options available in your current session.

Confirmed keyboard and mouse defaults

The browser control layer exposes the following default actions. A player can change supported actions from the live Controls & Settings panel; the table below describes the defaults in the current source configuration.

ActionDefault input
Primary fireLeft mouse button
Alternate fireMiddle mouse button

ReloadEnter

JumpNumpad 0
PeekNumpad 1

Previous weaponO
FullscreenAlt + Enter in the browser page

The Modern movement preset uses W, A, S and D. The live panel shows the active movement bindings and lets you select or rebind the available actions. Browser fullscreen is a page control; it is separate from the game's own menu.

Touch controls for supported devices

On supported phones and tablets, the page provides an on-screen movement stick and action buttons. The touch layer includes a layout editor for moving buttons and adjusting their size and opacity. Use touch swipes to aim, tap the available buttons for game actions and rotate the device to landscape when the player asks for it.

Gyroscope aiming

The controls code includes motion-sensor aiming modes and sensitivity settings. Depending on the browser and operating system, the page may require a user gesture or permission before motion input is available. When gyroscope input is unavailable or declined, use swipe aiming instead.

Widescreen, fullscreen and compatibility

The current build has a widescreen option for the 3D view. Some menus and scoped views retain 4:3 proportions. Fullscreen and pointer lock are browser-controlled features and normally need a user action. WebGPU, memory, storage and sensor permissions vary by device, so the presence of a setting does not guarantee that every browser or phone will support it.
