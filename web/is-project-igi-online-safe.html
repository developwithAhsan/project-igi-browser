Is Project I.G.I. Online Safe to Use?

A practical explanation of what this fan-made browser port does with your files, browser storage and device permissions.

Quick answer

This website does not provide a game download. You select your own legally obtained Project I.G.I. folder, and the browser stores an imported copy in private site storage on your device. Only use game files you have the right to use, and review browser permissions before granting them.

Does this site download the original game?

No. The website does not host or distribute the original commercial game files. You bring your own legally obtained copy. Avoid third-party pages that promise a free Project I.G.I. installer, crack or full-game download; this site does not endorse those downloads.

Where do the selected files go?

The port copies the selected folder into browser-managed origin storage (OPFS). The files are used locally by the browser runtime and are not uploaded to this site's server as part of the import flow. The storage belongs to this browser profile and origin, so clearing site data or using private browsing may remove the imported copy.

What permissions may be used?

Keyboard, mouse and touch input are needed to play. Gyroscope aiming can require motion-sensor permission on supported mobile browsers. Fullscreen and pointer-lock behavior are controlled by the browser and normally require a user gesture. You can decline motion access and use touch swipe aiming instead where available.

How to reduce risk

  • Use a current browser from its official update channel.
  • Only select game folders from a source you trust and are legally entitled to use.
  • Do not install unknown browser extensions or executable downloads promoted by unrelated sites.
  • Keep a backup of your original game folder.
  • Do not clear this site's storage if you want to keep the imported browser copy.
  • Close the game tab before clearing browser data or changing browser profiles.

Does the site use cookies or analytics?

The current code does not connect an approved analytics property. Third-party advertising code may be enabled separately and can involve third-party requests. This site's privacy and cookie pages describe the current implementation; they should be reviewed again before enabling new analytics or ad vendors.

Is it an official game website?

No. This is an unofficial fan project and is not affiliated with or endorsed by Innerloop Studios, Eidos Interactive or other rights holders. Read the fan project disclaimer and privacy policy before use.
