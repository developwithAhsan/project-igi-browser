Cookie & Browser Storage Policy

Cookies and browser storage are different technologies; this page explains how the game import works.

Browser storage for game files

The browser port uses origin storage (including the Origin Private File System where supported) to retain the game files you select. This is not the same as a tracking cookie. Clearing website data may remove the imported game copy.

Cookies and analytics

The current code has no approved analytics property connected. The site owner should add an analytics provider only after configuring the correct account and any required consent. Hosting and browser behavior may still involve essential technical storage.

Third-party advertising

When advertising slots are enabled, third-party ad resources may be requested. Those providers may use their own cookies or identifiers depending on browser policy and their configuration. The site owner should keep this policy aligned with the active ad vendor and consent requirements.

Manage storage

You can manage or clear site data through your browser settings. Be aware that removing this site's stored data can delete the imported game files and require you to select your own game folder again.
